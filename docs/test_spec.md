## 記録方法

各テストの実施記録に、テストID、対象コミットSHA、環境、手順、期待結果、実結果、合否、問題Issueへのリンクを含める。入力内容そのものや不要なデバイス固有識別子を公開ログへ記録しない。

## 合否の扱い

- **未実施**：実行していない。
- **合格**：期待結果を満たし、記録がある。
- **失敗**：期待結果を満たさず、再現情報とIssueがある。
- **保留**：仕様または性能目標が未確定で判定できない。
